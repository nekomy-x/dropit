## Test behavior

- DROP IT Test Club, DJ Test, an active session, price EUR 3.00.
- MockStripe only; the explicit test payment captures a simulated payment and
  queues the request through the regular backend. No card or real money needed.
- Catalog search uses the deployed catalog service. Club, DJ and admin panels
  use the live API, not demo data.
- The bootstrap QR expires 14 days after creation. Closing its session or
  rotating its QR invalidates the old guest link normally.
- Email, push and payment-provider credentials are not configured for this test
  stand. Account emails ending in `.test` are local login identifiers.

## Host

Ubuntu 26.04, x86_64, 1 GB RAM with 1 GB swap. Native systemd deployment:
`dropit-api`, `dropit-workers`, PostgreSQL 18, Redis, nginx and chrony. Public
ports are 22, 80 and 443; API, database and Redis listen on loopback.

Runtime env: `/srv/dropit/etc/dropit.env`. Binaries: `/srv/dropit/bin/`.
Web bundles: `/srv/dropit/web/`. Preserve the configured public URL values:

## Deployment and TLS

gitignored). Select it on every invocation:

```sh

DROPIT_DEPLOY_ENV="$PWD/deploy/prod/.env.15024168204.local" ./deploy/prod/deploy.sh --verify-only
```

Build web-club with
`VITE_GUEST_ANDROID_PACKAGE=com.example.dropit_guest.test204` for this host.
The isolated Android test build uses that application ID, label `DROP IT Test`,
API define `DROPIT_API_URL=https://150.241.68.204`, and Gradle property
`dropitGuestHost=150.241.68.204`. It can be installed alongside the regular app.
Do not publish a previously built APK that points at a different API.

Published APK: `/downloads/dropit-guest.apk`, version `0.1.1-test204` (code 3),
ARM64, 44,157,118 bytes. Flutter uses release AOT; Android R8 minification and
resource shrinking are disabled in this test build. Signed with the local test
debug certificate. APK metadata is available at `/downloads/dropit-guest.json`;
Android association at `/.well-known/assetlinks.json` uses its actual signing
certificate. The source snapshot and build logs are under
`output/vps204-mobile/` and `output/vps204-green-android-build.log` locally.
