# DROP IT 

Первоначальный документ проекта — приложение для заказа музыки в ночных клубах

## 1. ИДЕЯ

DROP IT — это приложение для ночных клубов, которое позволяет посетителям заказывать песни непосредственно у диджея со своего мобильного телефона, не подходя к диджейской кабине и не стоя в очереди.

Посетитель сканирует QR-код ночного клуба, входит в текущую сессию этого вечера, находит нужную песню и платит 2 € за отправку музыкального запроса. Запрос поступает непосредственно диджею.

## 2. РАСПРЕДЕЛЕНИЕ ОПЛАТЫ

Стоимость каждого запроса составляет 2 €.

Первоначальная схема распределения:

* 1,00 € → DROP IT
* 0,50 € → Диджею
* 0,50 € → Ночному клубу

Распределение должно осуществляться автоматически через платёжную систему с учётом комиссий платёжного провайдера, налогов и других применимых расходов.

## 3. ОПЫТ ПОЛЬЗОВАТЕЛЯ

Процесс должен быть максимально простым:

СКАНИРОВАТЬ QR → НАЙТИ ПЕСНЮ → ОПЛАТИТЬ → ЗАПРОС ОТПРАВЛЕН

После сканирования QR-кода:

DROP IT 🎧

DJ MARTIN

Сегодня вечером:
SALSA · BACHATA · MERENGUE

Что вы хотите услышать?

🔍 Найти песню

Пользователь может искать как новые, так и старые песни.

После выбора песни:

Marc Anthony — Vivir Mi Vida

Заказать песню — 2,00 €

Затем:

Оплата через Apple Pay / Google Pay / банковскую карту

После завершения оплаты запрос появляется в системе диджея.

## 4. МУЗЫКАЛЬНЫЕ СТИЛИ

Диджей должен иметь возможность выбирать музыкальные стили, которые он принимает в рамках текущей сессии.

Например:
- Salsa
- Bachata
- Merengue
- Rock
- Jazz

Цель — исключить запросы, которые не соответствуют музыкальной атмосфере вечеринки.

Система должна позволять диджею изменять выбранные музыкальные стили в течение ночи.

## 5. СТАРЫЕ И НОВЫЕ ПЕСНИ

Пользователь сможет искать как старые, так и современные песни из доступного каталога.

Не обязательно, чтобы диджей заранее подготовил песню, чтобы пользователь мог её запросить.

Окончательное решение о том, будет ли песня воспроизведена, принимает диджей.

Приложение должно технически изучить способы предоставления музыкального каталога и, особенно, вопросы лицензирования и авторских прав, необходимые для легальной работы сервиса.

## 6. ПОВТОРНЫЕ ЗАПРОСЫ

Одна и та же песня может быть запрошена и оплачена несколькими людьми.

Например:
 Песня X
7 запросов

Каждый из 7 человек самостоятельно отправляет запрос стоимостью 2 €.

Песня может быть воспроизведена только один раз.

Каждый платёж относится к отдельному запросу, а не к отдельному воспроизведению песни.

Перед оплатой пользователь должен чётко увидеть:

«Вы платите 2 € за отправку запроса на воспроизведение выбранной песни. Решение о воспроизведении остаётся на усмотрение диджея.»

А также:

«Если несколько человек запрашивают одну и ту же песню, каждый запрос оплачивается отдельно.»

## 7. ПАНЕЛЬ ДИДЖЕЯ

У диджея будет приложение/панель, где он сможет видеть:

* Полученные запросы.
* Запрошенную песню.
* Количество запросов одной и той же песни.
* Время запроса.
* Оплаченную сумму.
* Музыкальный стиль.
* Принять запрос.
* Отклонить запрос.
* Отметить песню как воспроизведённую.
* Временно закрыть приём запросов.
* Выбрать принимаемые музыкальные стили.

Запросы должны отображаться максимально удобно, чтобы диджей мог легко видеть их даже во время работы.

## 8. ПАНЕЛЬ НОЧНОГО КЛУБА

Ночной клуб сможет:

* Создать свой профиль.
* Создать сессию/вечеринку.
* Привязать диджея.
* Сгенерировать QR-код.
* Активировать/деактивировать QR-код.
* Просматривать запросы.
* Просматривать доходы.
* Просматривать статистику.

QR-код должен иметь возможность изменяться для каждой вечеринки или сессии.

## 9. АДМИНИСТРАТИВНАЯ ПАНЕЛЬ — DROP IT

Создатель DROP IT будет иметь административную панель, с помощью которой сможет контролировать:

* Зарегистрированные ночные клубы.
* Зарегистрированных диджеев.
* Пользователей.
* Активные сессии.
* Запросы.
* Платежи.
* Комиссии.
* Доходы.
* Статистику.
* Инциденты.
* Блокировки или приостановку аккаунтов.

## 10. ВИЗУАЛЬНАЯ ИДЕНТИЧНОСТЬ

Название: DROP IT

Логотип: минималистичные наушники

Стиль:
* чёрный фон.
* Белые буквы.
* Неоново-зелёный цвет в качестве акцента.
* Элегантный, современный и ночной дизайн.

Приложение должно передавать атмосферу музыки, ночи, вечеринки и технологий.

* Безопасную систему аккаунтов.

* Защиту персональных данных.
* Контроль доступа для клиентов, диджеев и ночных клубов.
* Защиту административной панели.
* Антифрод-систему.
* Регистрацию операций.

Право собственности на код, дизайн, торговую марку и другие разработанные элементы должно быть надлежащим образом документировано и передано компании/владельцу в соответствии с договором с разработчиком.

## 12. ПЕРВАЯ ВЕРСИЯ (MVP)

Для начала необходимо создавать все возможные функции.

Первая версия должна включать:

**КЛИЕНТ**
QR → Диджей/вечеринка → СТИЛИ → ПОИСК → ПЕСНЯ → ОПЛАТА 2 € → ЗАПРОС.

**ДИДЖЕЙ**
Вход в систему → музыкальная сессия → получение запросов → принять/отклонить → отметить как воспроизведённую.

**НОЧНОЙ КЛУБ**
Профиль → создать сессию → сгенерировать QR → базовая статистика.

**DROP IT**
Административная панель → пользователи → ночные клубы → диджеи → запросы → платежи.

После тестирования этой версии в нескольких ночных клубах можно будет добавить новые функции.

## 13. ЦЕЛЬ

Создать международную платформу, которую можно использовать в ночных клубах любой страны.

Система должна быть подготовлена для:

* Разных стран.
* Разных валют.
* Разных языков.
* Большого количества ночных клубов.
* Большого количества диджеев.
* Большого количества пользователей.
* Международного масштабирования.

**DROP IT — Твоя песня. Твоя ночь.** 🎧
