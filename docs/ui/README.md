# UI-прототипы (папка `apps/`)

HTML-прототипы в фирменном стиле DROP IT (чёрный / неон-зелёный `#a6ff00` / моно).
Служат заданием дизайнеру и фронтенду: состояния, данные, интеракции уже описаны.

## Что здесь

| Прототип | Файл | Покрывает (из `dizayn-zadanie.md`) |
|---|---|---|
| Консоль диджея | `apps/web-dj/index.html` | разделы 1.2–1.8: очередь, пауза, «сейчас играет», статистика вечера, состояния (пусто/офлайн) |

Открывается в браузере напрямую, без сборки. Данные — демо-моки поверх планируемого
REST-контракта gateway-api (F4): `GET /sessions/{id}/requests`, `POST /requests/{id}/accept|reject|played`.

## Дизайн-токены (ядро системы, раздел 5 задания дизайнеру)

- `--bg #050505`, `--bg-elev #0b0b0c`, `--bg-card #141416`, `--stroke #232326`
- `--text #f4f4f2`, `--text-dim #8a8a90`, `--text-faint #55555c`
- `--neon #a6ff00` (принять/деньги), `--red #ff3860` (отклонить/ошибка), `--amber #ffb800` (пауза), `--blue #4dd7ff` (время)
- Шрифты: Unbounded (display) + Space Mono (данные); для ночной читаемости DJ — ≥15px, высокие контрасты
- Радиусы: 20/14/9; движение: `--ease cubic-bezier(.22,1,.36,1)`, `prefers-reduced-motion` учтён
