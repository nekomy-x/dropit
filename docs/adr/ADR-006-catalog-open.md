# ADR-006: Каталог — статус ОТКРЫТ по лицензиям (B5)

**Статус:** ⛔ частично открыт; механика принята, внешние источники — до проверки
**Дата:** 2026-10-12

## Принятая механика (когда источники подтверждены)

1. Поиск выполняется **из клиентского приложения** (документы утверждают, что Apple блокирует серверные дата-центры для iTunes Search — требует проверки на реальном окружении).
2. Сервер **whitelist-валидирует** клиентский результат: домены cover/preview (например `*.mzstatic.com`, deezer), длины полей, canonical-ключ `source+source_id` пересчитывается и сверяется — защита от отравления кэша модифицированным клиентом.
3. Кэш: Redis по нормализованному `query+market` хранит **список id track_cache** (не копию метаданных); БД — upsert по `UNIQUE(source, source_id)`.
4. ISRC-обогащение — MusicBrainz серверно (rate 1 req/с).
5. Истекающие превью-URL: `preview_url_checked_at` + фоновый re-resolve.

## Открыто (блокер B5)

- Актуальные условия iTunes Search / Deezer / MusicBrainz API: права на метаданные, обложки, 30-сек превью в коммерческом продукте по странам.
- Реальная доступность клиентского поиска из стран пилота.
- Утверждение в КП «Spotify не отдаёт превью с 2024» — сверить с текущим состоянием.

## Следствия

F3 (каталог) не стартует до закрытия B5. Запросы/сессии/платформенные экраны от каталога не зависят; в тестовом контуре допускается только **явно помеченный** синтетический набор треков.
